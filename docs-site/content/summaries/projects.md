# Projects & workflows

Projects organize workflows. Team permissions control who can use them; projects do not restrict execution.

## Organize your work

1. Select your organization and team.
2. Open **Projects** and create a project.
3. Choose **Open project** to browse its workflows, or create a new one.
4. Open a workflow to view its canvas and details.

## Before deleting

A project must be empty before it can be deleted; the default General folder is protected. A workflow can be deleted only if it has never been published. Deleting a draft does not erase its audit/run history or cancel an active test.
