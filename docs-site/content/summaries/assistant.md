# Lumi assistant

Use Lumi to discuss workflows and review scoped authoring proposals.

## Start a conversation

1. Select a team and open **Lumi**, or press **⌘K / Ctrl+K**.
2. Type a message. Enter sends; Shift+Enter adds a line.
3. Keep typing while replies stream. Queue another message or stop the current response.
4. Use **New chat** when you need a fresh conversation.

Messages are private to you within the selected team. If no model is configured, chat still saves messages and explains that the LLM is not configured.

## Understand its scope

General chat is discussion-only. In a saved workflow, Lumi can propose new child drafts and attach them to the current parent after your review.

It cannot publish, execute workflows, activate schedules, edit existing children or read secret values. Unsaved canvas edits are not supplied to the model.

Provider setup, queue limits and recovery details are in the technical reference.
